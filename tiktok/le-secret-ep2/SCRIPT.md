# Le secret — Partie 2 · script

Titre : **COMMENT SAVOIR SI TA FAMILLE TE MENT · Partie 2** — ~55 s, même style (papier découpé, leçons du narrateur).
Série prévue : 3 parties (4 si ça marche).

Deux débuts selon le vote (A = il ouvre / B = il se cache), puis la même suite. On publie celle que le public a choisie.

## Début A — il ouvre (≈8 s)
- N : « Imagine… Tu ouvres la porte. »
- N : « Le couloir est vide… »
- N : « Par terre… la photo de famille. »

## Début B — il se cache (≈9 s)
- N : « Imagine… Tu restes caché. »
- N : « La poignée tourne… puis s'arrête. »
- N : « Sous la porte… quelqu'un glisse une photo. »

## Suite commune
- N : « Sur la photo… tu n'es plus là. »                    (gros plan : l'enfant découpé)
- LEÇON 4 : « Quand quelqu'un te dit de ne croire personne… c'est lui qu'il faut croire le moins. »
- N : « Imagine… ton téléphone vibre. Et c'est elle. »                  (« Maman · appel entrant… », téléphone censé être éteint)
- Mère : « Tu as trouvé la photo ?… Alors il sait. »
- Mère : « Celui qui t'écrit… n'est pas ton père. »
- Mère : « Ton vrai père… c'est celui qui a sonné. »         (coup sourd, rouge)
- LEÇON 5 : « La vérité ne frappe jamais à la porte. Elle a déjà la clé. »
- N : « Imagine… en bas, la porte d'entrée s'ouvre. »               (clé dans la serrure, lumière du rez-de-chaussée)
- N : « Tu descends… ou tu passes par la fenêtre ? Vote en commentaire. »   (cartes A 🏃 Je descends / B 🪟 La fenêtre)
- N : « Abonne-toi. Partie 3 demain. »

Demande de Wilfried : utiliser « Imagine… » pour que les gens se projettent davantage dans l'histoire.
