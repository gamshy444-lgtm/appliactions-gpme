# Le secret — Partie 2 · script

Titre : **COMMENT SAVOIR SI TA FAMILLE TE MENT · Partie 2** — ~55 s, même style (papier découpé, leçons du narrateur).
Série prévue : 3 parties (4 si ça marche).

Deux débuts selon le vote (A = il ouvre / B = il se cache), puis la même suite. On publie celle que le public a choisie.
