# Journal vidéos — ce qu'on a appris

## 27/11/2026 — Bilan

**Résultats**
- Aucune vidéo n'a percé (Facebook, Instagram, YouTube Shorts).
- Aucune vidéo au-dessus de 10 000 vues.
- Seule exception : la vidéo sur **David Lisnard**, sur Facebook.
- Ce qui marche le mieux : les vidéos sur les **ministres / personnalités politiques candidates**. Mais même elles n'ont pas vraiment percé.
- Les concepts précédents ont été jugés mauvais.

**Décision** : il faut faire nettement mieux, sinon on arrête le projet.

**Nouvelle méthode adoptée** : triple hook (contexte, curiosité, contre-pied) + structure en 4 étapes (moment, conséquence, changement, action concrète). Détail dans `stop-motion-design/SKILL.md`, section 2 bis.

**Lecture**
- TikTok : plancher ≈ 700 vues = l'algorithme teste la vidéo puis la coupe → le hook ne retient pas.
- Les 2 seules vidéos TikTok qui sortent du plancher ont un **angle conflit / contre-pied** (« ne doit PAS ») ou un **enjeu personnel d'argent** (« plus que toi »).
- Le format « Imagine si X président » plafonne partout sauf Lisnard et Le Pen sur Facebook → format usé.
- Facebook : les mesures économiques chiffrées en première ligne (Lisnard, Le Pen) marchent mieux, mais on n'a qu'**un seul vrai succès** → hypothèse à tester, pas une certitude.
- Trop de sujets différents (Napoléon, Teddy Riner, storytime, 49.3) → l'identité de la chaîne n'est pas claire.
