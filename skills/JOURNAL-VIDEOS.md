# Journal vidéos — ce qu'on a appris

## 27/11/2026 — Bilan

**Résultats**
- Aucune vidéo n'a percé (Facebook, Instagram, YouTube Shorts).
- Aucune vidéo au-dessus de 10 000 vues.
- Seule exception : la vidéo sur **David Lisnard**, sur Facebook.
- Ce qui marche le mieux : les vidéos sur les **ministres / personnalités politiques candidates**. Mais même elles n'ont pas vraiment percé.
- Les concepts précédents ont été jugés mauvais.

**Décision** : il faut faire nettement mieux, sinon on arrête le projet.

**Nouvelle méthode adoptée** : triple hook (contexte, curiosité, contre-pied) + structure en 4 étapes (moment, conséquence, changement, action concrète). Détail dans `stop-motion-design/SKILL.md`, section 2 bis.
